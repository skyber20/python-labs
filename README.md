# Лабораторная работа № 1

---

## Описание 
В рамках первого спринта реализована базовая архитектура платформы для обработки задач. Система представляет собой агрегатор, который собирает данные из различных источников (файлы, API, генераторы), приводит их к единому формату и передает на дальнейшую обработку в виде потока (генератора), обеспечивая фильтрацию дубликатов и отказоустойчивость.

---

## Запуск проекта
Установка зависимостей
```bash
pip install -r requirements.txt
```

Запуск main.py (Демонстрации работы, не CLI)
```bash
python main.py
```
Логи будут сохраняться в logs.log (в корне проекта)

Запуск тестов с покрытием (90%)

```bash
pytest --cov=task_processor
```
